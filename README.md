# 関数電卓

.NET 8 / WPF で作成した電卓です。四則演算は乗除算を加減算より優先し、同じ優先順位は左から計算します。例：2 ＋ 3 × 4 ＝ 14。値と演算子をスタックで管理し、優先順位は `ExpressionEvaluator.cs` の `Precedence` で定義しています。

平方根（√x）、逆数（1/x）、二乗（x²）、階乗（n!）は表示中の数値に直ちに適用します。演算子の直後に押した場合は、表示中の値を次の項として使います。階乗は 0〜27 の整数に対応します。ゼロ除算、負数の平方根、階乗の範囲外、計算結果のオーバーフローはエラー表示になります。平方根には double を用いるため近似値となります。

Windows の Visual Studio 2022 で `Calc1.sln` を開いて実行してください。「.NET デスクトップ開発」ワークロードと .NET 8 SDK が必要です。C は全消去、⌫ は１文字削除、± は符号反転です。
